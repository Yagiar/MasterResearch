# СВОДКА ЦИКЛА «АНСАМБЛЬ ДВУХ МОДЕЛЕЙ» (it-74…80, 21–22.09.2026)

Назначение: единая опора для главы диплома — какие утверждения об ансамбле old⊕new
поддержаны замерами, где границы применимости и что осталось открытым.
Каждое утверждение ниже имеет указатель на итерацию и артефакт; числа — только из
закоммиченных `.csv/.txt` (канон воспроизведения: `REPRODUCE.md` §6f–6l).

## Рамка: почему ансамбль

Цикл одиночных рычагов (it-69…73: порог, вход SAHI, политика fusion, выбор весов)
закрылся выводом «безобученные рычаги одиночной модели исчерпаны» (с рамкой LESSONS:
*над перебранными измерениями*, не «вообще»). Следующее измерение — функция решения
двух моделей (old = канон `visual-uav-yolov8s`, new = дообученная семка), без обучения.

## Утверждения (claim → evidence)

1. **CONF-AND@0,40 — первая зелёная пара осей E5×E1 за цикл (G1/G2 зелёные).** 94,7 % /
   7,2 %: доминирует одиночный old (94,5/27,5 — реколл +0,2 п.п. при FP вчетверо ниже);
   относительно new@0,4 (94,8/10,2) old-фильтр срезает FP до 7,2 ценой 0,1 п.п. реколла;
   относительно лучшей по FP одиночной точки new@0,5 (84,3/6,5) — реколл +10,4 п.п. при
   +0,7 п.п. FP. Устойчивость: блочный бутстрап
   [92,2; 96,9] / Уилсон [5,1; 10,2], сид 20260921. Дальний бакет 89,3 % (G3).
   → `iterations/it-74-two-model-vote.md`, `it74_vote_grid.csv`, `it74_vote_bootstrap.txt`.
2. **Контурная линейка ансамбля — по OR-ряду, не по AND.** OR-ряд в каркасе it-71
   даёт R=1,000 / F1=0,965 / FP=8 (K1–K3 зелёные; канон old F1=0,961), единственный
   old-FN развёрнут. В image-домене OR красен (FP 49,8 %) → доставка двухрядная:
   image=AND@0,40, контур=OR. → `it-75-contour-vote-rows.md`.
3. **Матрица покрытия E-осей закрыта согласованно:** FP-согласие min-ряда на старых
   фонах 5,6 % (Δ с V1 1,6 п.п.), presence «стоящего» 18/18 (E4 не тронута);
   E7/E8 n/a по конструкции. → `it-76-ensemble-e-coverage.md`.
4. **Merge боксов (NMS-union) — отрицательно по mAP (E2/E3).** Харнес воспроизвёл
   все 4 одиночных канона в ±0,010 (блокатор), после чего merge-NMS: dut 0,8737 vs
   new 0,9014; hf 0,8798 vs 0,8861 — H1 красен; механизм: union наследует FP-профиль
   old (29k детекций), WRF-справка ещё хуже (0,58/0,55). → `it-77-ensemble-nms-map.md`,
   `it77_ensemble_map.{csv,txt}`.
5. **Семейство мягких голосований M_p не улучшает AND@0,40 (D1 красен).** 55 точек
   p∈{−8…8}×τ∈{0,30…0,50}: внутренние p движутся вдоль Парето-фронта AND↔OR; ни одна
   не доминирует (при зелёных сами-проверках против it-74). Рамка вывода:
   «исчерпано над p-семейством средних», НЕ «исчерпано вообще».
   → `it-78-gmean-vote.md`, `it78_gmean_vote.{csv,txt}`.
6. **FP-точка AND@0,40 не робастна к режиму входа HD+SAHI (X1/X2 красные).** На 400
   чистых HD-фонов Open Images (min-сторона 768…4032, CC, ¬aerial — бэклог it-73 закрыт)
   FP(AND@0,40) = 48,8 % против 7,2 % на 640-px COCO (V1): медиана 24 тайла/кадр
   умножают per-frame max_conf, сдвиг согласован у обеих моделей (old 86,2 / new 50,5)
   → эффект режимный, не модельный; в старой сетке τ не спасает (AND@0,50 = 34,2 %),
   на HD требуется собственная перекалибровка порога. → `it-79-hires-sahi-bg.md`,
   `it79_sahi_hd_fp.{csv,txt}`.
7. **Однородный HD-профиль ансамбля не существует в барах E5×E1 (H1/H2 красные, it-80).**
   При R-ряду из того же HD/SAHI-режима (MMAUD, 5018 полётных) и FP-ряду it-79 (400 HD-фонов)
   FP(AND)≤12,8 % впервые при τ=0,70, где R(AND)=25,3 % (бар 85 %); при этом τ
   ΔR(AND−max одиночных)=−6,4 п.п. → у FP-бара ансамбль уже **хуже** лучшего одиночного ряда.
   Следствие для формулировок: зелёная пара 94,7/7,2 — **смешанный режим** (R из SAHI-HD
   видео, FP из 640 full-frame COCO); как однородное HD-утверждение не переносится и
   перекалибровкой τ не спасается (в пределах сетки). → `it-80-hd-uniform-profile.md`,
   `it80_hd_profile.{csv,txt}`.

## Итоговый профиль (для формулировок в диссертации)

Ансамбль двух YOLO-моделей в задачах обнаружения БПЛА даёт измеримый выигрыш **только
как по-рядная функция решения**: conf-AND@0,40 для покадрового решения (пара
94,7/7,2 — первая зелёная пара E5×E1 цикла) и conf-OR для событийного контура
(F1 0,965 > канона). Осторожность с режимом входа (it-79/it-80): пара 94,7/7,2 собрана из
**смешанных режимов** (R — SAHI на 1080p-видео MMAUD, FP — 640-px COCO); на 400 чистых
HD-фонах Open Images FP(AND@0,40) = 48,8 % вместо 7,2 %, а однородная HD-точка в барах
E5×E1 отсутствует и перекалибровкой τ не достигается (при первом FP≤12,8 % на τ=0,70
R=25,3 %, и AND уже хуже лучшего одиночного на −6,4 п.п.). Для HD/SAHI-доставки профиль
ансамбля требует отдельной калибровки с HD-разметкой обеих осей — в диссертации это
граница применимости, а не опровержение (640-px full-frame режим — штатный режим конвейера
диплома). Объединение боксов (merge-NMS) и мягкие усреднения conf (M_p)
выигрыша не дают: merge стабильно ниже лучшего одиночного по mAP50 на обеих
подвыборках, точки M_p лежат на том же фронтере, что AND/OR. Ограничение доставки: ×2 инференса/кадр — инженерное
решение автора; подтверждение на живом контуре (A/B, аналог it-68) — **открытый
вопрос**, офлайн-материал (один тест-материал, независимости нет) его не закрывает.

## Методологические уроки цикла (см. также LESSONS навыка ai-research)

- Вывод об «исчерпанности» формулируется строго над перебранным измерением (рамка
  «исчерпано над X»); it-78 — исполнение этого правила как отдельной итерации.
- Любой новый mAP-харнес проходит блокататор воспроизведения канонов (±0,010) до
  вердикта; GPU-инженерия предсказуемо дорога: OOM по RAM (чанки+cache=False),
  CUDA OOM (batch=1, expandable_segments), синтетический `r.path` (ключ по порядку).
- Вердикт дефектного прогона не выносится: сами-проверки/аналитический selftest
  формулы — блокатор интерпретации (it-78, первый запуск).
