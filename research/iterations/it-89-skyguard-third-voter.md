# it-89 — skyguard как третий voter: zero-inference disagreement-гейт (предрегистрация)

**Статус: ПЛАН.** P3 по `DECISION-roadmap-post-it82.md`: прогон-кандидат в живой контур
допускается **только** после анализа согласованности на рядах, полученных без нового инференса.
Стоп-критерий роадмапа: «нет complementary signal → закрыть отрицательно без GPU-прогона».

## Гипотеза

Третий voter (shelf-skyguard-v11, E5 90,9 %) несёт комплементарный сигнал: на множестве
расхождений old≠new его решение разрезает связку в правильную сторону (спасает полётные
FN и/или режет фоновые FP) достаточно, чтобы политика MAJ3 превзошла действующую
AND_presence_live@0,4 по обеим осям одновременно.

## Данные (ноль инференса; закоммиченные ряды)

- MMAUD SAHI-ряды (img-ключ media_ts, `conf_sahi`): old `mmaud_sahi_full.csv`,
  new `mmaud_sahi_full_new.csv`, skyguard `mmaud_sahi_full_skyguard-v11.csv` (5091 кадров,
  GT полёт z>1,0 как it-74).
- COCO-фоны V1 (400 независимых кадров, `max_conf`): `coco_bg_fp_it69v1-old.csv`,
  `coco_bg_fp_it69v1-new.csv`, `coco_bg_fp_skyguard-v11.csv`.

## Определяемые величины

Бинаризация каждой модели по τ; **D** = множество расхождений old⊕new (разные исходы);
**tie-break skyguard**: на D решение = skyguard≥τ, вне D — общий голос old=new.
- `rescued_TP(τ)` — полётные кадры из D с ошибочным общим мнением old=new=0, спасённые skyguard=1;
  на самом деле old≠new на D, поэтому считаем по policy: TP(tie-break) − TP(AND₂@τ) на flight;
- `introduced_FP(τ)` — FP(tie-break) − FP(AND₂@τ) на фонах;
- `rescue_precision = rescued_TP / (rescued_TP + introduced_FP)`;
- свойства политики: AND₃(минимум трёх) ⊆ AND₂; MAJ₃ ⊇ AND₂ — проверить численно (самопроверка).

## Предрегистрированные проверки

- **Q0 (сами-проверки):** join трёх рядов MMAUD = 5091 = каждый; join фонов = 400;
  воспроизведение канонов it-70/74: skyguard flight recall@0,5 = 90,9 % (±0,2 п.п.),
  old@0,5 = 94,5 %, new@0,5 = 84,3 %; вложенности AND₃⊆AND₂⊆OR₂ и AND₂⊆MAJ₃ (проверка
  на множествах, не по агрегатам).
- **Q1 (complementary signal):** ∃ τ ∈ {0,35; 0,40; 0,45; 0,50}: tie-break policy против
  AND₂@τ даёт rescued_TP ≥ 5 кадров **и** rescue_precision ≥ 0,90 **и** introduced_FP ≤ 2.
- **Q2 (превосходство действующей политикой):** MAJ₃@0,4 против AND₂@0,4: ΔR(flight) ≥ +1,0
  п.п. **и** ΔFP(фоны) ≤ +1,0 п.п. одновременно.
- **Вердикт-гейт:** Q1 ∨ Q2 → skyguard допускается к планированию GPU-прогона (отдельная
  итерация, до it-87 и вне рамок holdout); ¬Q1 ∧ ¬Q2 → **it-89 закрывается
  отрицательно без GPU-прогона** (стоп-критерий роадмапа).

## Рамки (фиксирую до замеров)

- Офлайн-единица — кадр (пофреймово), не событие и не live-контур; HD/SAHI режим входа,
  перенос в live не предполагается.
- 400 фонов COCO и 5091 кадр MMAUD — тот же development-материал цикла; итоговый freeze
  остаётся за it-87.
- τ=0,4 — операционная точка действующей политики; свитч τ справочный.
