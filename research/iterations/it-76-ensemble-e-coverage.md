- **Триггер:** it-74/75 открыли рычаг «ансамбль» и дали по нему две точки (image AND@0,40,

## Конструкция (фиксируется ДО чисел)

1. **Матрица покрытия E1–E8 × {AND@0,40, OR-ряд}**: для каждой ячейки — измерено (номер
   итерации+число) / не измеримо без нового материала / пробел (что нужно). Матрица —
   документационный результат, числом не является.
2. **Доизмер Ф** (E1-аналог на втором выборке фонов): `coco_bg_fp_{old,new}-yolov8s-*.csv`
   (90 фонов it-65, боевой набор E1) — FP-доля min-ряда ≥0,4; сверяется с V1-400 значением
   7,2 % it-74 как consistency-чек по пересэмплированию. Порог совпадения предрегистрируется:
   |Ф − 7,2 %| ≤ 8 п.п. (н+м 90 кадров: биномиальный ±≈8 п.п. при p≈0,07).
3. **Доизмер С** (E4-аналог по «стоящему дрону»): `session_vis_probe_{old,new}.csv`
   (18 с negative-session) — доля секунд, где min(max_conf) ≥ 0,4 (presence-TP ансамбля).
   Канон E4: old 18/18. Предрегистрированный барьер: С ≥ 16/18, иначе ансамбль подрывает
   E4-ось и это регистрируется красным пятном профиля.
4. Никаких новых критериев доставки/экспорта итерация НЕ вводит: экспорт по-прежнему требует
   плеча T (пауза автора) или полноценной ансамбль-линейки (см. матрицу).

## Что заведомо вне замера (предрегистрированные пробелы матрицы)

- E2/E3 (mAP на DUT/HF600): ансамблевая mAP требует слияния боксов (NMS-мердж двух рядов) —
  функция решения над боксами, исключена предрегистрацией it-74 («иные правила — вне итерации»);
  для неё нужен отдельный прогон predict с обоими весами (GPU-инференс разрешён автором) —
  регистрируется как будущая итерация, здесь — пробел.
- E7/E8 (аудио/stress-оси): визуальное голосование аудио-ветку не меняет → «n/a по конструкции».
- Живой A/B ансамбля (аналог it-68): требует правки visual-detector на 2 модели — вне офлайн-рамок.
