# ИТЕРАЦИЯ 59 — SAHI-нарезка внедрена в visual-detector: живой прогон на MMAUD даёт recall присутствия 100% (e2e 1.1 с)

- **Дата:** 2026-09-06
- **Источник:** it-56/58 (масштабный доменный разрыв видео, SAHI-потенциал); ревью §10.
- **Артефакты:** `visual_detector/detector.py` (SAHI-сетка + NMS-мердж, конфиг `sahi_slice/sahi_overlap`), `factory.py`, `configs/pilot.yaml`, `visual-detector/tests/test_sahi.py` (+4), `research/mmaud_sahi_eval.py`, `research/mmaud_sahi_eval.csv`, `research/target_validate_run.sh` — и методологическая находка (см. §4).

## Реализация

`YoloDetector.detect()` при `sahi_slice > 0`: кадр нарезается сеткой slice×slice с перекрытием (крайние срезы прижимаются к краям — покрытие 100%), каждый срез инференсится отдельно, детекции переводятся в глобальные координаты и сливаются NMS (порог iou). Конфиг: `visual_detector.sahi_slice / sahi_overlap` (0 = выключено). Тесты: покрытие сеткой (2560×960 → 10 срезов, края закрыты), NMS-мердж кросс-срезовых дублей, глобальные координаты. **79/79 → 83/83 тестов** (visual-detector +4).

## 4. Методологическая ловушка (третий случай одного класса!)

Первый live-прогон дал 0–23% positive. Диагностика (снятие кадров из video.raw + офлайн-SAHI на них: дрон есть 0.62–0.73) → корень: **env-имена в override-файле** — `UAVDET_VISUAL__*` попадают в секцию `visual` (несуществующую), а секция называется `visual_detector` → правильные имена `UAVDET_VISUAL_DETECTOR__*`. Live-детектор работал БЕЗ SAHI с imgsz 640 на полном кадре 2560×960 → recall ~17–23% (согласуется с it-56). После исправления имён — 100%.

Это третий случай одного класса ошибок (it-52/53: override не включён в compose up; it-59: env-префикс не совпадает с секцией конфига). Правило для будущих прогонов: **проверять эффективную конфигурацию сервиса внутри контейнера (docker exec … load_config) до измерений**, а не только факт наличия env.

## Следствия

1. Рабочая конфигурация визуальной ветки для панорамных сцен: `imgsz 640 + sahi_slice 640/0.2` (лучше, чем imgsz 1920 полный кадр, при меньшей латентности) — recall присутствия 100% на MMAUD V1 Mavic3, e2e 1.1 с.
2. Остаточные ограничения: латентность SAHI ~10 инференсов/кадр (для 5 fps на GPU — приемлемо); неточность локализации bbox малой цели не оценивалась (только присутствие).
3. С «стоит/летит» на MMAUD (GT-высота) в SAHI-режиме можно вернуться к motion-признаку: при SAHI-кропе цель крупнее — скорость центра снова информативна (проверка — it-60 при необходимости).
