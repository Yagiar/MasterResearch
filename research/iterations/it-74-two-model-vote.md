# ИТЕРАЦИЯ 74 — Популяционное голосование двух моделей (old⊕new): AND/OR по conf, ноль инференса — AND@0,40 даёт первую зелёную пару E5×E1 (94,7 %/7,2 %)

- **Дата:** 2026-09-21. **Статус:** завершена (вердикт в «Результатах»; предрегистрация — коммит 3743ed6).
- **Гипотеза:** пересечение решений двух checkpoints (старые майские + uav-yolov8s-bg) на
  **операционной точке τ=0,4** (уже предрегистрированной Парето-точкой new из it-70
  `it70_threshold_tradeoff.txt`) одновременно держит SAHI-recall полёта ≥ 89,5 % (E5) и
  FP на независимых фонах ≤ 12,8 % (E1) — т.е. ансамбль «чувствительность old × специфичность
  new» закрывает разрыв, который не закрыл ни один одиночный рычаг it-69…73.

## Почему это новый рычаг, а не перелицовка

it-69…73 двигали **порог над одной моделью** или **вход** (SAHI). Голосование меняет
**функцию решения** над двумя рядами conf; a priori нет причины, по которому оно исчерпано
раньше. Арифметическая мотивка: AND@0,5 ⊆ new@0,5 ⇒ G1 для AND@0,5 невыполним в принципе
(recall ≤ 84,3 %); но AND@0,4 ⊇ (per-frame both≥0,4) и new@0,4 уже даёт 94,8 % при FP 10,2 % —
old-фильтр сверху может лишь улучшать FP, теряя recall внутри зазора 94,8−89,5 = 5,3 п.п.

## Данные (все join-ы проверены структурно, исходы не открывались)

- полёт/дальн: `mmaud_sahi_full.csv` (conf_sahi old) ⋈ `mmaud_sahi_full_new.csv` (conf_sahi new), 5091/5091;
- фоны: `coco_bg_fp_it69v1-{old,new}.csv` (full-frame @640, 400/400; геометрия постоянна внутри оси);
- контур: `yolo_sandbox_frames{,_new}.csv` (imgsz480, секундный ряд) + каркас it-71 (AST pa, окна 0,5 с).

## Правила (pre-defined функции, τ∈{0,35; 0,40; 0,45; 0,50})

- `AND_τ` := min(c_old, c_new) ≥ τ; `OR_τ` := max(c_old, c_new) ≥ τ. (Иные правила — MAX-conf
  ансамбль с NMS, взвешенные средние — вне итерации: требуют боксов, это уже новый прогон.)

## Предрегистрированные критерии (основная ячейка — AND@0,40; остальное — справочная сетка)

- **G1 (E5-аналог):** recall полёт AND@0,40 ≥ 89,5 % (порог E5, тот же материал MMAUD).
- **G2 (E1-аналог):** FP на 400 независимых фон AND@0,40 ≤ 12,8 %.
- **G3 (дальний бакет, диагностика):** дальн10-19 AND@0,40 ≥ 80,4 % (под-порог it-70).
- **G4 (контур, каркас it-71, pv := AND-ряд, гейт 0,25, D0):** R ≥ 0,98 ∧ F1 ≥ 0,95 ∧ FP ≤ 8.
- **Правило вердикта:** G1∧G2 зелёные → ансамбль регистрируется **кандидатом офлайн-линейки**
  (G4 — требование для контурной заявки; G3 — отчётная деталь, не блокатор).
  G1∧G2 красные → голосование закрыто; вывод «только рецепт T» остаётся.
- **Справка, не критерий:** OR-сетка (ожидаемо ≈ old: recall ↑, FP ↑), сетка τ целиком.

## Ограничения (заранее)

1. **Цена доставки:** 2 инференса на кадр (≈×2 латентность/VRAM; на 5 fps GPU — терпимо,
   но это другой профиль поставки, чем одиночная модель — решение автора, вне итерации).
2. Оба ряда conf измерены **на одном и том же** материале (MMAUD/фоны/песочница) — это

3. new-ряд — одна семка (урок it-69 п.2); ансамбль наследует это ограничение.
4. Дистанционные бакеты — та же конвенция `it70_shelf_report.py` (GT-высота/дальность MMAUD).

## Результаты (2026-09-21, ноль инференса; все 6 сами-проверок канонов — OK)

Сетка τ (полёт / FP400): AND@0,35 → 97,1 % / 9,2 %; **AND@0,40 → 94,7 % / 7,2 %**;
AND@0,45 → 90,2 % / 6,0 %; AND@0,50 → 82,7 % / 5,2 %; OR@0,35 → 100,0 % / 49,8 %;
OR@0,40 → 99,8 % / 42,8 %; OR@0,45 → 99,1 % / 36,0 %; OR@0,50 → 96,2 % / 28,7 %.
Дальн10-19 (AND): 94,2 / 89,3 / 80,6 / 66,8 % по τ. Полные ряды — `it74_vote_grid.csv`.

**ВЕРДИКТ основной ячейки AND@0,40: G1 ЗЕЛЁНЫЙ (94,7 % ≥ 89,5), G2 ЗЕЛЁНЫЙ (7,2 % ≤ 12,8),
G3 зелёный (89,3 % ≥ 80,4), G4 КРАСНЫЙ (R 0,946 < 0,98; F1 0,942, FP 7, FN 6).**
→ ансамбль регистрируется **кандидатом офлайн-линейки**; контурная заявка НЕ заявлена.

1. **Пара E1×E5 зелёная впервые за цикл it-69…74** — и до, и после держалась дилемма
   «old: 94,5/27,5 ↔ new: 84,3/6,5». AND@0,40 лежит ПРАВЕЕ обеих одиночных точек:
   recall 94,7 % ≥ old-канона при FP 7,2 % — вдвое ниже порога E1. Мотивка подтвердилась:
   old-фильтр сверху с new@0,4 (94,8/10,2) срезал FP до 7,2 при потере 0,1 п.п. recall.
   AND@0,45 — вторая зелёная пара (90,2/6,0), вне предрегистрированной ячейки (справка).
   *Эрратум (21.09, SYNTHESIS-ensemble.md п.1): «правее обеих» неточно — AND@0,40 доминирует
   old (94,5/27,5); относительно new-точек это размен: vs new@0,4 (94,8/10,2) — FP −3 п.п.
   ценой 0,1 п.п. реколла; vs new@0,5 (84,3/6,5) — реколл +10,4 п.п. при +0,7 п.п. FP.*
2. **Механизм G4-провала** — тот же класс, что «recall без pari passu точности» (LESSONS):
   min-ряд **снижает** pv на airborne-окнах, где old или new поодиночке давали conf;
   FN контура растёт (new 5 → AND 6), R падает ниже 0,98. Голосование по min помогает
   против ложных срабатываний (фоновые ряды почти не пересекаются) и вредит на границах
   решения в контуре — асимметрия по природе сигнала.
3. OR-сетка ≈ ожидаемому («как old, только шире»): recall↑ FP↑, не кандидат.
4. Ограничения в силе (п.1–2 «Ограничений»): цена доставки ×2 инференса — **решение автора**;
   материал совпадает с E-линейкой (не независимое подтверждение); new — одна семка.
   Для экспортной заявки нужен живой A/B (аналог it-68) — отдельная итерация.
