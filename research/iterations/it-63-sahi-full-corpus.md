# ИТЕРАЦИЯ 63 — Полный SAHI-прогон всего корпуса MMAUD: recall «летит» 94.5%, union 95.5% — окончательная цифра видео-ветки на независимом материале

- **Дата:** 2026-09-06
- **Источник:** завершение it-58 (SAHI-проба была на 62 пропущенных кадрах; точная цифра на всём корпусе не зафиксирована).
- **Артефакты:** `research/mmaud_sahi_full.py`, `research/mmaud_sahi_full.csv` (5091 строка: conf_full1920 + conf_sahi + union по каждому кадру).

## Метод

SAHI (640/0.2, срезы @640) на ВСЕХ 5091 кадре независимого корпуса MMAUD V1 Mavic3 (~33 мин GPU), мерж с уже измеренным full@1920 (it-58) по каждому кадру. Recall присутствия (GT: дрон присутствует во всех кадрах) по состояниям «стоит/летит» (GT-высота) и по третям полёта.

## Результаты (окончательные для видео-ветки на независимом материале)

| Метод | СТОИТ (n=49) | ЛЕТИТ (n=5018) |
|---|---|---|
| полный кадр @1920 | 8.2% | 64.5% |
| **SAHI 640/0.2** | **100.0%** | **94.5%** |
| union (любой из двух) | 100.0% | **95.5%** |

Union recall по третям полёта: 93.8% → 95.1% → 97.6% — равномерно высокий, без провалов по фазам.

Важно: **SAHI-режим сам по себе (без full-frame) даёт 94.5% на полёте и 100% на статике** — выборка 510 кадров (82.7%) недооценивала. Полный кадр @1920 на этом материале не нужен: SAHI 640/0.2 доминирует и по recall, и по латентности на кадр.

## Следствия

1. **Окончательная цифра видео-ветки на независимом панорамном материале: recall присутствия 95.5% (union) / 94.5% (чистый SAHI)** против 18.3% у наивной конфигурации @960. Доменный разрыв устранён конфигурацией полностью.
2. Рабочая конфигурация для панорамных сцен: `imgsz 640 + sahi_slice 640/0.2` (уже в коде, it-59), full-frame @1920 как fallback.
3. Замечание: recall «стоит» 100% при SAHI — стоящий дрон тоже детектируется (для target=airborne гасится аудио-подтверждением it-55; для presence — корректный TP).

## Ограничения

- Латентность SAHI ~10 инференсов/кадр (~250 мс на GPU) — для реального времени на 6 ГБ GPU приемлемо до ~4 fps; выше — imgsz 1920 полный кадр (64.5%) или оптимизация батчинга срезов.
- Одна секвенция V1; V2/V3 (Carpark) — при загрузке.
