# ИТЕРАЦИЯ 07 — Стресс-симуляция: устойчивость политик fusion к деградации аудио

- **Дата:** 2026-09-04
- **Цель:** офлайн-аналог «канала деградации» из пайплайна: как политики слияния (it-06) ведут себя при потере/шуме аудио-окон AST. Каждая точка — mean±std по 25 сидам.
- **Артефакты:** `research/stress_sim.py`, `research/stress_sim_results.csv` (108 строк).
- **База:** 144 смешанных окна YOLO×AST (it-06), GT `airborne`. Стрессы: WindowDrop (окно теряет аудио с вероятностью p), NoiseDegradation (p_a′ = p_a + N(0,σ)), Outage (аудио пропадает на последних X% клипа).

## Выводы

1. **late+медиана-5 (по валидным окнам) — самая устойчивая политика**: лучший F1 без стресса (0.922), грациозная деградация при дропе (0.888 при 60% дропа — всё ещё выше video-only), лучший при outage, шумоустойчивость до σ≈0.4 (0.837). Проигрывает только при экстремальном шуме σ=0.6.
2. **Иммунные, но безвыигрышные**: video-only / w_v=0.9 / consensus держат ровно 0.871 при любом стрессе (аудио ими не используется) — это «пол безопасности», не развитие.
3. **Δ-правило вредит под шумом**: 0.756 против 0.823 у чистого late при σ=0.2 — двойной штраф за шумные противоречия каналов. Кандидат на ослабление (δ уменьшать при низкой уверенности канала).
4. **Имплементационный урок (важно для патча fusion):** кодировать пропавшие окна нулями ДО медианы — уничтожает пользу медианы (0.755 против 0.888 при 60% дропе). Медиану считать только по валидным окнам; пропуск ≠ ноль.
5. Катастрофический режим прогона №3 (F1 0.40) при случайной деградации не воспроизводится: она требует **систематически уверенно-ошибающегося** канала, а не потери/шума. То есть «канал деградации» пайплайна надо тестировать и на систематический сдвиг (например, подмена аудио на нерелевантное), а не только на шум/дроп.

## Связь с пайплайном

Стратегии `WindowDrop`/`AudioNoise`/`ModalityDropout` в `source-simulator` создают именно такие условия; результаты it-07 предсказывают их исход до запуска и дают критерий валидности будущего ablation-прогона со стрессами: late+медиана должна деградировать по кривым выше.
