# ИТЕРАЦИЯ 62 — 4-канальная решётка MMAUD: каналы взаимно некоррелированы — аудиоузел писал только шум предусилителя; акустическая ветвь на V1 закрыта окончательно

- **Дата:** 2026-09-06
- **Источник:** план it-61 §4 (дообучение «или отказ»); проверка последнего ресурса — микрофонной решётки.
- **Артефакты:** `research/mmaud_multichannel.py`, `research/mmaud_audio{1..4}_6k.wav`, `research/mmaud_audio_avg_6k.wav` (на диске).

## Метод

Полное извлечение всех 4 каналов решётки из ROSBag (198–199 с каждый, 6 кГц). Проверка гипотезы: каналы — независимые записи одной сцены → усреднение 4 каналов подавляет некоррелированный шум (~6 дБ) и проявляет когерентный сигнал дрона.

## Результаты

1. **Попарные корреляции каналов: 0.004–0.007** — каналы не содержат НИКАКОГО общего акустического содержимого. Для исправной решётки, пишущей одну сцену, корреляция когерентных источников (дрон — точечный источник) была бы существенной даже с учётом межканальных задержек.
2. **Усреднение 4 каналов: RMS 0.560 → 0.282 (ровно /2)** — математически возможно только если каждый канал есть чистый независимый шум: когерентная компонента (сигнал дрона) с ненулевой мощностью дала бы падение меньше 2x. **Мощность общего сигнала ≈ 0.**
3. Спектральный контраст полёт/статик на усреднённом канале: 0.96–1.03 по всем полосам (контроль sandbox: 11x) — сигнатуры нет и после усреднения.

## Вывод: аудиоузел MMAUD V1 неисправен (писал шум предусилителя)

Микрофонные «каналы» bag — не записи сцены, а независимый электронный шум (микрофоны отключены/не оцифровывались). Это окончательный вердикт по акустике V1: **восстановить или усреднить нечего — сигнала нет ни в одном канале**. Акустическая ветвь на независимом материале закрыта на уровне железа записи; не модель, не алгоритм, не усреднение — источник данных.

Для диссертации: зафиксировано измеренное требование к записывающему тракту (направленные микрофоны, gain staging, ≥ 16 кГц, верификация записи по корреляции каналов ДО эксперимента — метод it-62). Система в конфигурации SAHI + audio-подтверждение корректно работает на таком домене (video-only, 0 FP от аудио).

## Ограничения

- Вердикт относится к V1 Rooftop Simple; V2/V3 bag могут иметь исправный аудиотракт — при загрузке первым шагом та же корреляционная проверка (скрипт готов, ~40 мин на bag).
- Аудио 6 кГц — даже исправный тракт не дал бы полосы выше 3 кГц.
