# ИТЕРАЦИЯ 78 — Семейство обобщённого среднего над парой conf (p-сетка): закрытие измерения «функция голосования» (ПРЕДРЕГИСТРАЦИЯ 2026-09-21)

- **Дата:** 2026-09-21. **Статус:** ждёт замера (ноль инференса — существующие CSV).
- **Триггер:** урок LESSONS от 21.09 («исчерпано над X, а не „исчерпано“»): it-74 измерил
  ДВЕ крайние точки функции голосования — AND=min (p→−∞) и OR=max (p→+∞) — и ничего между
  ними. Между тем AND@0,4 (94,7 % / 7,2 %) — это компромисс на лобовом отрезке между new@0,4
  (94,8 % / 10,2 %) и точкой жёсткого пересечения; мягкое пересечение (обобщённое среднее) —
  незанятая внутренность пространства, и именно её отсутствие в переборе делает вывод
  «голосование изучено» пока неверифицированным.

## Конструкция (фиксируется ДО чисел)

- Ряд: `M_p(c_old, c_new) := ((c_old^p + c_new^p)/2)^(1/p)` — обобщённое среднее;
  предельные точки сетки: p→−∞ = AND (минимум), p→+∞ = OR (максимум).
- Сетка: p ∈ {−8, −4, −2, −1, −0,5, 0,25 (=геометрическое), 0,5, 1 (арифметическое), 2, 4, 8}
  × τ ∈ {0,30; 0,35; 0,40; 0,45; 0,50} (τ — шаг сетки it-70). Числовые значения M_p
  считаются в loge-пространстве (устойчиво к conf=0: нулевой член ⇒ M_p=0 при p>0 — совпадает
  с AND-семантикой; при p<0 нуль доминирует корректно через exp(logaddexp(−∞))).
- Материал и метрики — КАНОНИЧЕСКИЕ ряды it-74 (без новых прогонов):
  полёт/дальн: `mmaud_sahi_full.csv` ⋈ `mmaud_sahi_full_new.csv` (5091 кадр, GT-высота z>1,
  дальн 10–19 м); FP: `coco_bg_fp_it69v1-{old,new}.csv` (400 независимых фонов, доля кадров
  с M_p ≥ τ); контур (для выбранной точки): каркас it-71/75, pv := M_p-ряд, гейт 0,25, D0.

## Предрегистрированные критерии

- **D1 (доминирование):** существует (p, τ) с полёт-реколлом ≥ 94,7 % И FP ≤ 7,2 % И
    хотя бы одной строгой компонентой (реколл ≥ 95,5 % ИЛИ FP ≤ 6,0 %) — тогда эта точка
    регистрируется НОВЫМ кандидатом image-линейки вместо AND@0,40.
- **D2 (Парето-карта):** для каждой τ печать границы реколл×FP по p — отчётный артефакт,
    не блокатор.
- **D3 (контур, только если D1 зелёный):** M_p-ряд в каркасе it-75: K1 R ≥ 0,98 ∧
    K2 F1 ≥ 0,95 ∧ K3 FP ≤ 8. D1 красный ⇒ контур не считается (нет предмета).
- **Правило вердикта:** D1 красный ⇒ измерение «функция голосования» закрывается ЧЕСТНЫМ
    отрицанием: сетка из 55 внутренних точек + 2 границы не улучшает frontier AND@0,40 —
    вывод it-74 распространяется на всё семейство средних (рамка «исчерпано над p-семейством»).
    D1 зелёный ⇒ пересмотр кандидата (image=M_p; контур — по D3).

## Ограничения (заранее)

1. Тот же материал, что it-74 (конвенция цикла): подтверждения независимостью нет; живой A/B
   по-прежнему вне (решение автора о ×2).
2. Цена доставки не меняется: 2 инференса/кадр.
3. Дальний бакет и интервальные запасы — справочно; при зелёном D1 бутстрап новой точки —
   отдельным дополнением (как it-74), критерии не меняются.
4. Сетка p дискретна; непрерывная оптимизация (p, τ) по тому же материалу — переобучение
   метрики на оценочном наборе, сознательно НЕ делается.
