Две находки:

1. **Корпус практически без негативных кадров** (1 пустая разметка из 54 071 = 0,002 %). YOLO обучен на ~100 % позитивах — это объясняет поведение видео-ветки на негативных сценах (склонность к «всегда дрон» без фонового контекста). Действие: добавить фоновые кадры (пустые изображения из DUT/SAHI-источников, 5–10 % корпуса) при следующей переподготовке.
2. **Сценарная группировка не верифицируема по именам**: у всех кадров источника hf-drone-detection префикс оригинала — только «train»/«test» (метаданные сцен в именах отсутствуют). Сплиты источника использованы как есть (явные split'ы, it-37), но независимость «сцен внутри сплита источника» не подтверждается манифестом — ограничение датасета, зафиксировано.
