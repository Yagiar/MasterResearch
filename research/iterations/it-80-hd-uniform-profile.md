# it-80 — Однородный HD-профиль ансамбля (ноль инференса)

Статус: ЗАВЕРШЕНА 22.09.2026 (H1/H2 красные — см. «Результаты»; предрегистрация — коммит ef59c0c до замера).
Плечо: без обучения; только анализ закоммиченных CSV.

## Гипотеза / вопрос

it-74 собрала зелёную пару E5×E1 (94,7 % / 7,2 %) из **смешанных режимов**: ряд recall —
MMAUD-полёт при SAHI на нативных 1920×1080 (HD-режим), ряд FP — COCO-фоны ≤640 px
(SAHI ≡ full-frame 640, постскриптум it-73). it-79 измерила: в HD/SAHI-режиме FP на чистых
фонах смещается до 48,8 % (AND@0,40). Вопрос итерации: **существует ли на HD однородная
рабочая точка ансамбля** (обе оси в одном режиме входа), и сохраняет ли AND-механизм
преимущество над лучшими одиночными точками при перекалиброванном τ?

## Данные (все — закоммиченные артефакты, новых прогонов нет)

- R-ряд (HD-позитивы): `mmaud_sahi_full.csv` / `mmaud_sahi_full_new.csv` (поле `conf_sahi`,
  5091 кадр; GT — `train/data/mmaud/Mavic3/ground_truth/*.npy`, полёт z>1, дальн 10–19;
  дословные функции `gt_at`/join из `it74_vote_analysis.py`). n: полёт 5018, дальн10–19 2351.
- FP-ряд (HD-фоны): `it79_old.csv` / `it79_new.csv` (поле `max_conf`, 400 HD-фонов OI,
  tile 640/0,2 — тот же SAHI-режим, что и позитивный ряд).
- Ряды ансамбля: AND := min(old,new), OR := max (конвенция it-74).

## Протокол

Сетка τ = {0,30; 0,35; 0,40; 0,45; 0,50; 0,55; 0,60; 0,65; 0,70} ×
{old, new, AND, OR} × {R_полёт, R_дальн10–19, FP_HD} → `it80_hd_profile.csv` (+ .txt отчёт).

**Сами-проверки (блокатор интерпретации, до вердикта):**
1. MMAUD: old@0,5 = 94,5 % ± 0,2; new@0,5 = 84,3 % ± 0,2 (каноны it-74);
2. it79-фоны: FP(AND@0,40) = 48,8 % ± 0,1 (канон it-79);
3. join-полные: 5091 из 5091; 400 из 400.

## Критерии

- **H0 (блокатор):** все сами-проверки зелёные; иначе вердикт не выносится.
- **H1 (главный):** существует τ* ∈ {0,55; 0,60; 0,65; 0,70} с FP(AND@τ*; HD-фоны) ≤ 12,8 %
  **и** R(полёт; AND@τ*) ≥ 85,0 % → «на HD есть однородная рабочая точка ансамбля в профиле
  E5×E1 (со сдвигом в высокие τ)». Иначе H1 красный → ограничение: на HD профиль ансамбля
  недостижим в зарегистрированных барах FP/recall (перекалибровка τ не спасает).
- **H2 (выигрыш на HD):** при τ* из H1 (если H1 зелёный; иначе — при минимальном τ из
  {0,55…0,70} с FP(AND) ≤ 12,8 %): ΔR := R(AND@τ*) − max(R(old@τ*), R(new@τ*)) ≥ +1,0 п.п.
  → преимущество ансамбля переживает HD-режим; иначе красный → на HD ансамбль не лучше
  лучшего одиночного ряда (ограничение в SYNTHESIS).
- **H3 (справочно):** фронтир τ×ряды целиком; медианные/крайние точки; без порога вердикта.

## Ограничения (заранее)

1. Материалы осей разные (MMAUD-позитивы vs OI-фоны) — как в V1; однородным является
   **режим входа** (SAHI-HD), не сюжеты.
2. FP-бар 12,8 % зарегистрирован для COCO-фонов; уровень FP на OI-фонах может отличаться
   и по материалу (Flickr-сюжеты) — вывод формулируется «на HD-материале it-79».
3. Дисперсии режима нет (по одному ряду на модель); τ-сетка конечна.
4. R-ряд MMAUD — те же кадры, что в it-74 (зависимость выводов итераций от одного
   положительного материала остаётся).

## Результаты (22.09.2026)

**H0 — зелёная** (все сами-проверки exact: old@0,5 94,5; new@0,5 84,3; FP(AND@0,40;HD) 48,8;
join 5091/400; полёт 5018; дальн 2351). Числа it-74/it-79 сошлись дословно → ряды те же.

Фронтир τ×ряд (R_полёт / FP_HD, %; полный — `it80_hd_profile.csv`):

| τ     | old        | new        | AND        | OR         |
|-------|------------|------------|------------|------------|
| 0,40  | 99,8/86,2  | 94,8/50,5  | 94,7/48,8  | 99,8/88,0  |
| 0,50  | 94,5/75,0  | 84,3/37,8  | 82,7/34,2  | 96,2/78,5  |
| 0,55  | 85,5/68,0  | 74,0/32,8  | 70,7/27,8  | 88,8/73,0  |
| 0,60  | 70,6/55,8  | 60,4/28,0  | 56,2/21,8  | 74,8/62,0  |
| 0,65  | 53,1/43,2  | 45,1/22,0  | 41,6/15,8  | 56,6/49,5  |
| 0,70  | 31,7/28,2  | 29,3/15,0  | 25,3/9,8   | 35,7/33,5  |

- **H1 — КРАСНЫЙ.** FP(AND;HD)≤12,8 % впервые при τ=0,70 (9,8 %), но R(AND)=25,3 % ≪ 85 %:
  однородная рабочая точка в барах E5×E1 **не достигается** ни на одном τ∈{0,55…0,70}.
- **H2 — КРАСНЫЙ (деградация механизма).** При τ=0,70 (единственном τ с FP≤12,8):
  ΔR = R(AND) − max(R(old),R(new)) = 25,3 − 31,7 = **−6,4 п.п.** — в высокопороговой HD-области
  AND-ряд проваливается быстрее одиночных (совместное подавление уверенных детекций на
  мелком объекте в нативном разрешении). Выше 0,70 — вне предрегистрированной сетки;
  экстраполяция не заявляется.

**Вердикт:** профиль ансамбля 94,7/7,2 (it-74) — свойство **смешанного режима** (R из SAHI-HD
на 1080p-видео, FP из full-frame 640 на COCO); в однородном HD-режиме он не воспроизводится
и не спасается перекалибровкой τ на сетке — при достижении FP-бара ансамбль уже **хуже**
лучшего одиночного ряда. Формулировка для диплома: «преимущество CONF-AND измерено и
обосновано для режима входа 640px full-frame; перенос в HD/SAHI-режим не подтверждён
(it-79, it-80) и требует отдельной калибровки с целевой HD-разметкой». Ограничение
регистрируется в SYNTHESIS-ensemble (claim №7) и итоговом профиле.

Механизм (справочно, без порога): с ростом τ FP-ряды сходятся медленно (old: 75→28, new:
38→15, AND: 34→10 на τ 0,5→0,7), а R-ряды обваливаются быстро (AND 82,7→25,3) — HD-тайлы
дают фону много «уверенных» мелких структур, которых нет у позитивного материала MMAUD
(один дрон, предсказуемая величина). Это различие геометрии материалов, а не режимов, —
главный кандидат-объяснение красной H1; в этой итерации не изолируется.
