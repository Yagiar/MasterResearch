## 1. Архив цел; «Damaged» — ложная тревога архиватора

CRC-проверка всех 11797 файлов: **No errors detected**. Файл 10.75 ГБ — zip64-контейнер; сообщение «Damaged» — ограничение GUI-архиватора. Извлечено в `train/data/mmaud/Mavic3/`: image (5091 PNG, 2560×960, ~30 fps, **169.8 с**), ground_truth (833 npy — 3D-позиция дрона), radar_enhance_pcl (2549), lidar_360 (1623), livox_avia (1699). Формат листинга OneDrive: ROSBag Data (.bag) / Folder Data (.zip) / Ground truth (.bag) — скачан только Folder Data.

## 2. Аудио в Folder Data НЕТ

Только .npy и .png. Аудиопоток (микрофонные массивы) остаётся в **ROSBag Data** (.bag, DJI Mavic3 V1 — 11.1 ГБ). Следствие: акустическая калибровка порога на MMAUD требует скачать ROSBag и извлечь аудио из bag (решение пользователя: 11.1 ГБ).

## 3. Независимая визуальная валидация: доменный разрыв, в основном масштабный

YOLOv8s-uav (обучена на DUT Anti-UAV + Drone-vs-Bird) на 5091 кадре MMAUD (дрон всегда присутствует по GT; GT-высота z даёт метку «стоит/летит»):

| imgsz | recall «летит» (≥0.5) | conf медиана (полёт) | recall «стоит» |
|---|---|---|---|
| 960 (текущий пилотный) | 18.3% | 0.192 | 0.0% |
| 1280 | 27.1% | 0.291 | 0.0% |
| **1920** | **64.5%** | **0.594** | 8.2% |

**Прежний вывод «видео-ветка не имеет доменного разрыва» (it-04) верен только для фрейминга sandbox.** На панорамной rooftop-сцене дрон мал; при imgsz 960 модель его практически не видит (p_v медиана 0.195). Повышение разрешения инференса до 1920 восстанавливает recall до 64.5% (остаточный разрыв + вероятен выигрыш от 2560/SAHI — согласуется с it-25 «imgsz1280 +25%»).

## 4. Re-test признака движения (it-52/53) на реальном полёте

Неинтерпретируем на этом материале: дрон на панораме занимает единицы пикселей, bbox-нормированная скорость насыщается (медианы 0.9–1.0 в обоих состояниях). Для видео-признака состояния нужны оптический поток или кроп-трекинг (увеличение окрестности трека), не скорость центра.

## 5. Следствия для диссертации

1. Честная формулировка: «визуальная ветка не имеет доменного разрыва» → «отсутствие разрыва подтверждено только для фрейминга обучающих данных; на панорамных сценах с малым дроном требуется imgsz ≥ 1920 (recall 18% → 64.5%)».
2. Режим target=airborne с video-motion на панорамных сценах не работает (см. п. 4) — аудио-подтверждение (it-55) остаётся единственным носителем «активен».
3. Акустическая ветка на независимом материале — после ROSBag (аудио внутри bag).
