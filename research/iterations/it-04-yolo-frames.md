# ИТЕРАЦИЯ 04 — YOLO на кадрах sandbox: видео-домен-гэп отсутствует

- **Дата:** 2026-09-04
- **Цель:** проверить видеоветку на целевом домене (аудио имело domain gap; есть ли у видео?) — офлайн-инференс обученной YOLOv8n→UAV на 73 кадрах клипа против GT.
- **Артефакты:** `research/yolo_frames_eval.py`, `research/yolo_sandbox_frames.csv` (146 строк: imgsz 480/640 × 73 с).
- **Условия:** `models/visual/yolov8s-uav.pt` (наш fine-tune), CPU, порог детекции варьировался 0.25/0.5 (в пайплайне conf_threshold=0.25).

## Результаты

| Конфигурация | vs `visible` | vs `airborne` |
|---|---|---|
| imgsz=480, thr=0.25 (как в пайплайне) | P=1.000 R=1.000 **F1=1.000** | P=0.753 R=1.000 F1=0.859 |
| imgsz=480, thr=0.5 | F1=1.000 | F1=0.859 |
| imgsz=640, thr=0.25 | F1=1.000 | F1=0.859 |
| imgsz=640, thr=0.5 | F1=0.986 | F1=0.841 |

Распределение уверенности: **на земле медиана conf=0.843, в воздухе 0.711** — стоящий дрон крупнее/контрастнее, летящий — мельче.

## Выводы

1. **Видео-домен-гэпа на этом клипе нет**: recall 100% при обоих порогах и обоих imgsz — детектор находит дрона в каждом кадре целевого домена (тёмный зал, мелкий объект). Контраст с акустикой (lwcnn 0% на том же клипе) разителен — доменная хрупкость у модностей разная.
2. P=0.753 против `airborne` — это НЕ ошибки детектора, а семантика: на стоянке дрон в кадре есть (детектор прав для `visible`-задачи), но неактивен. Ещё одно подтверждение it-02: целевую переменную для fusion надо определять явно.
3. **Валидация фазы it-03**: офлайн-recall 100% (видео видит дрона всегда) согласуется с онлайн video-only TRUE=99.9% (jsonl, 14094/14086) — фазовая привязка решений к секундам клипа корректна.
4. imgsz 640 ничего не даёт на этом клипе (recall и так 1.0); его ценность — для мелких/дальних дронов (it-01), здесь не проверяется.
5. Уверенность на стоянке выше, чем в полёте — любопытный артефакт для главы «анализ»: «задача детекции присутствия объекта проще, чем активного» — детектор любит крупные статичные объекты.

## Ограничения

- Один клип, 73 кадра, разметка 1 к/с — выводы про «отсутствие видео-домен-гэпа» масштабируются только на этот сценарий (тёмный зал, близкий дрон). Для дальних/уличных сцен нужен другой материал (MMAUD).
- Офлайн-инференс без трекера ByteTrack (в пайплайне решения проходят через трекер) — для оконных решений это роли не играет.
