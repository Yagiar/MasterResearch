# ИТЕРАЦИЯ 25 — YOLO11/YOLO26 vs YOLOv8: что брать в магистерскую

- **Дата:** 2026-09-04
- **Цель:** решить, переезжать ли визуальной ветке диссертации с YOLOv8 на YOLO11/YOLO26: зрелость, малые объекты, совместимость с пайплайном (ByteTrack).
- **Источники:** [официальное сравнение YOLO11 vs YOLOv8](https://docs.ultralytics.com/compare/yolo11-vs-yolov8), [YOLO26 model page](https://docs.ultralytics.com/models/yolo26), [end2end guide](https://docs.ultralytics.com/guides/end2end-detection), [обзор YOLO11 (arXiv:2410.17725)](https://arxiv.org/html/2410.17725v1), [сравнительное исследование YOLOv8–YOLOv12 (ScienceDirect)](https://www.sciencedirect.com/science/article/pii/S2949798126000050), [GitHub discussion о reID на NMS-free](https://github.com/orgs/ultralytics/discussions/23400).

## Факты

| Аспект | YOLOv8 | YOLO11 (сент. 2024) | YOLO26 (сент. 2025) |
|---|---|---|---|
| COCO nano | 37.3 mAP | **39.5 mAP** (+2.2) | н/д (edge-фокус) |
| m | база | **+1.3% mAP при −22% параметров** | н/д |
| Архитектура | C2f | **C3k2 + C2PSA (attention под малые объекты)** | DFL удалён, **end-to-end NMS-free** |
| CPU-инференс | база | ~ | **до −43% времени** |
| Зрелость | максимальная (экосистема, деплой) | зрелая, тот же API | ранняя (мало независимых оценок) |
| ByteTrack/reID | ✅ работает | ✅ работает | ⚠️ **плохо на NMS-free (end2end=True)** — [discussion #23400](https://github.com/orgs/ultralytics/discussions/23400) |

Для малых объектов: C2PSA действительно целится в них, но исследования всё равно добавляют P2-головы и нарезку (согласуется с it-01: SAHI/imgsz — приёмы первого порядка, смена версии — второго).

## Рекомендация для магистерской

1. **Базовая модель — остаётся YOLOv8n→UAV**: воспроизводимость, готовые результаты (mAP@0.5 0.881), прямое сравнение с ВКР [36]. Переезд сломал бы сравнимость всей накопленной таблицы.
2. **YOLO11n — дешёвый сравнительный эксперимент** (тот же ultralytics API, тот же датасет/пороги; ожидание: +1–2 mAP и −параметры): одна строка в главе «модели» — «базовая (YOLOv8) vs современная (YOLO11)» — стандартная структура магистерской.
3. **YOLO26 — отложить и не брать в текущую архитектуру**: NMS-free выдача конфликтует с ByteTrack (наш трекинг-контур), зрелость низкая. Вернуться в edge-главе: −43% CPU-инференса заманчиво для ноутбучного сценария, но только после стабилизации экосистемы (или с трекером, совместимым с end2end).
4. Формулировка для текста: «детектор — YOLOv8 [26]; архитектурная эволюция семейства (YOLO11 [26*], end-to-end YOLO26) рассмотрена в сравнительном эксперименте» — то есть сравнение как элемент исследования, а не замена базовой линии.

## Проверка совместимости с нашим пайплайном

- YOLO11: `ultralytics`-пакет тот же, `model.train()/predict()` без изменений; выгрузка best.pt совместима с `visual-detector` (проверено on it-04 — инференс через `YOLO()` идентичен). ByteTrack работает (NMS-based выдача сохранена).
- YOLO26: требует проверки `end2end` флага и поведения ByteTrack — блокер до стабилизации.
