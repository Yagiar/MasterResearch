# ИТЕРАЦИЯ 75 — Контур на pv-рядах ансамбля old⊕new: OR-ряд как последняя незанятая ячейка (ПРЕДРЕГИСТРАЦИЯ 2026-09-21)

- **Дата:** 2026-09-21. **Статус:** ждёт замера (ноль инференса; все ряды на диске).
- **Триггер:** it-74 закрыла ансамбль для контура только для одного ряда — AND (pv=min,
  красный G4: R 0,946). Симметричный **OR-ряд (pv=max)** не измерен ни в it-74 (её правило
  предрегистрировало только min), ни в it-71 (там политики над ОДНОЙ моделью). it-73
  предсказывает механизм: raising pv → рост FP на границах (насыщение), но это гипотеза,
  а не измерение.
- **Гипотеза:** найдётся pv-ряд ансамбля, который держит контурную тройку не хуже канона
  old (R 0,991 / F1 0,961 / FP 8) — т.е. ансамбль переносим и в контур, а не только в
  image-линейку.

## Ряды (pre-defined, ровно два — иных не добавлять)

- `AND` := min(c_old, c_new) — воспроизведение G4 it-74 (самопроверка: R 0,946 / F1 0,942 / FP 7);
- `OR` := max(c_old, c_new) — основная ячейка итерации.
- Каркас: it-71/it-74 (144 AST-окна, pa из `ast_windows.csv`, imgsz480 секундные ряды
  `yolo_sandbox_frames{,_new}.csv`, гейт 0,25 — боевой, политика D0 0,5·pv+0,5·pa ≥ 0,5).

## Предрегистрированные критерии (для OR-ряда; копия тройки G4)

- **K1:** R ≥ 0,98. **K2:** F1 ≥ 0,95. **K3:** FP ≤ 8.
- Сами-проверки до вердикта: канон old (0,961/0,991/FP 8), канон new (0,946/0,955/FP 7),
  AND-ряд it-74 (0,942/0,946/FP 7) — побитово с `it74_vote_analysis.txt`.
- **Правило вердикта:** K1∧K2∧K3 зелёные → «контурная заявка ансамбля пересматривается
  отдельно» (ряд с max-conf = тот же класс риска насыщения, что SAHI в it-73: точность
  на фонах меряется не контуром, поэтому зелёный K-триплет НЕ отменяет красный G2-риск —
  это регистрируется как гипотеза для живой проверки, не как результат).
  Любой красный → **ансамбль закрыт для контура**: вывод — контур остаётся на каноне old,
  ансамбль = исключительно image-линейка (и то с ×2-ценой доставки, решение автора).
- FP-окна OR-ряда выводятся списком (механизм: границы взлёта/посадки, как в it-73).

## Ограничения (заранее)

1. Тот же песочный материал n=1 сессия (урок it-72: независимого контурного материала нет) —
   это завершение сетки «ряд × каркас», не подтверждение.
2. OR-ряд в image-домене = OR@τ (it-74: FP до 49,8 %), т.е. зелёный контур при красных
   фонах не делает доставку привлекательнее — регистрируется механизм, не поставка.
