# ИТЕРАЦИЯ 79 — SAHI-FP на крупноразрешающих чистых фонах (Open Images): закрытие бэклога `hi-res-bg-for-sahi-fp` (ПРЕДРЕГИСТРАЦИЯ 2026-09-21)

- **Дата:** 2026-09-21. **Статус:** ждёт замера (GPU-инференс разрешён автором; загрузки публичных данных НА машину — вне git).
- **Триггер:** постскриптум it-73: на локальных COCO-фонах (≤640 px) SAHI тождественен
  full-frame ⇒ W4 («SAHI-FP») была неизмерима. Также это первая проверка устойчивости
  FP-доказательства ансамбля AND@0,40 (V1=7,2 % измерено на 640-px full-frame) к режиму
  входа «HD-кадр + тайлинг».

## Источник данных (зафиксирован ДО чисел; верифицирован HEAD-запросами 21.09)

- Open Images v5/v6 validation: список `https://storage.googleapis.com/openimages/2018_04/validation/validation-images-with-rotation.csv`
  (ImageID, OriginalURL Flickr, License per-image, OriginalSize); аннотации
  `openimages/v5/validation-annotations-bbox.csv`; классы `v5/class-descriptions-boxable.csv`.
- Фильтры отбора (детерминированные, сид 20260921): (1)OriginalSize min-сторона ≥ 768;
  (2) License строка содержит `creativecommons` (CC BY/BY-SA/BY-NC; «all rights reserved» — отсев);
  (3) исключение кадров с любым bbox-классом aerial-семейства по точным кодам из
  class-descriptions: Airplane, Helicopter, Drone/UAV (если есть в листе), Kite, Parachute,
  Hot air balloon, Balloon; (4) случайная выборка 400 + резерв 150 (битые Flickr-URL ожидаемы).
- Постфильтр по факту (блокатор): PIL-проверка фактических пикселей min≥768 у 100 % принятых;
  класс-проверка повторная по скачанным аннотациям; дубликаты по MD5 — отсев.
- Лицензионная рамка: только локальное научное использование; перераспределения изображений
  нет (в git не попадают, `data/_prepared` вне репозитория); аннотации OI CC BY 4.0.
- Контаминация: ни old (майские UAV-веса), ни new (uav-yolov8s-bg+MMAUD) не обучались на OI;
  COCO-негативы в текущих весах отсутствуют (плечо bg70 на паузе) — источник независим от V1.

## Протокол замера

Тот же tile-протокол, что it-73 (`it73_coco_sahi_fp.py --file-list`, слайсы 640, overlap 0,2,
conf 0,05, NMS внутри кадра по max_conf; GPU, device cuda, venv MasterDiploma). Выход —
`img,n_boxes,max_conf` на кадр для old и new; ряды ансамбля: AND_τ := min(max_conf_old,
max_conf_new) ≥ τ, OR — max (конвенция it-74 на уровне «кадр-максимум»).

## Предрегистрированные критерии

- **X0 (блокатор выборки):** принято ровно 400 кадров; 100 % с фактической min-стороной ≥768;
  ноль aerial-классов в финальной выборке; 100 % лицензии CC*. Не выполнено — вердикт не выносится.
- **X1 (главный критерий ансамбля):** FP(AND@0,40; SAHI-HD) ≤ 12,8 % (порог E1/V1).
- **X2 (consistency с V1):** |FP(AND@0,40; SAHI-HD) − 7,2 %| ≤ 8 п.п. (диапазон Φ it-76).
- **X3 (справочно):** FP old@{0,4;0,5}, new@{0,4;0,5}, OR@0,4; медиана тайлов/кадр; доля кадров
  с птицами в аннотациях (страта интерпретации, не критерий).
- **Правило вердикта:** X1∧X2 (при зелёном X0) → FP-доказательство AND@0,40 робастно к режиму
  входа (full-frame 640 → SAHI HD); W4-ось реестра закрывается измеренным фактом для ансамбля.
  Красный X1 или X2 → регистрируется НОВОЕ ограничение профиля: в HD/SAHI-режиме FP-профиль
  ансамбля смещается (число и знак — из замера); на вердикт it-73 (W2 красная) не влияет.

## Ограничения (заранее)

1. Flickr-домен: разрешения/сюжеты не из UAV-распределения — это и есть смысл «чистого фона»,
   но темп FP может отличаться от оперативных сцен (небесные кадры с птицами/линиями — отмечаем стратами).
2. Один прогон на модель (сид застройки выборки 20260921), дисперсии режима нет.
3. Ориентация тайлинг-геометрии: для сторон >640 SAHI даёт ≥2 тайла ⇒ метрика несопоставима
   с V1 напрямую — поэтому сравнение через диапазоны X1/X2, а не тождество.
4. Масштаб затрат: до ~800 MiB–2 GiB диска на 550 картинок; тайловый инференс линейен по площади.
