## Конструкция замера (фиксируется ДО чисел)

- Временная сетка: 1-секундные бины по видео-таймстампам; pv = max `conf_sahi` в бине
  (SAHI-протокол E5, гейт инференса 0,05 уже в CSV); детекторный гейт g: pv<g→0.
- Состояния из лидарного GT: airborne z>1, ground z<0.5, переходные секунды — вне оценки
  (конвенция E5). Событие = непрерывный airborne-участок.
- Метрики на (веса, g): window-recall airborne-бинов (= analogue E6), медианная задержка
  первого положительного бина от старта события, FP-доля на ground-бинах.
- Веса: old (`mmaud_sahi_full.csv`), new (`mmaud_sahi_full_new.csv`); g ∈ {0,25 (боевой
  поставки), 0,4 (кандидат it-69), 0,5 (исследовательская точка E5)}.
- Поздняя fusion-строка (D0 0.5·pv+0.5·pa) считается справочно и ожидается красной у всех
  (pa≈0,075) — это НЕ вердикт fusion-модели, а констатация переносимости ограничения
  it-57 на контурный уровень; в вердикт C-критерии не входит.

## Предрегистрированные критерии

- **C1 (механизм):** new@0,25 airborne-recall < old@0,25 − 0,02 → подтверждает, что
  песочная потеря окон new обобщается на независимый материал (иначе — песочная потеря
  была частной, что тоже результат).
- **C2 (окно):** new@0,4 airborne-recall ≥ old@0,25 − 0,02.
- **C3 (цена окна):** FP-доля new@0,4 на ground-бинах ≤ FP old@0,25 + 0,05.
- **C4 (задержка):** медиана задержки new@0,4 ≤ медиана old@0,25 + 1,0 с.
- Вердикт: «пара (new, 0,4) подтверждена на независимой видеосессии» = C2∧C3∧C4
  (C1 — интерпретационный, не блокирующий). Экспорта по-прежнему НЕ разрешает
  (плечо T на паузе; экспорт требует полного E1–E8 на bg70/канонном материале).

## Ограничения (вписывать в каждый вывод)

- Одна независимая сессия, тот же дроне-класс; ground-бинов мало (28 аудио-окон статики)
  → доверительные интервалы FP широкие; это подтверждение механизма, не финальная валидация.
- Аудио-канал не переносится (it-57) → контурное суждение о fusion на этом материале
  невозможно; E7/E8 на независимом материале остаются незакрытыми (отдельный открытый
  вопрос реестра).
- Видео-конф здесь из SAHI-протокола (тайлы 640), а боевой E6 считался на imgsz 480
  без нарезки — сравниваются тренды, не абсолютные числа.

## Результаты (21.09 ~20:52 МСК, `research/it72_independent_e6.py` → `.txt`)

- **Зарегистрированный замер (pv = посекундный МАКС conf_sahi) оказался НАСЫЩЕННЫМ:**
  airborne-recall = 100 % для ОБЕИХ весов при всех g∈{0,25; 0,4; 0,5}; ground-бинов — 3;
  airborne-событие — одно (166 с). C1 «не подтверждён» — но это не отсутствие потери, а
  неспособность линейки её увидеть (max-агрегация по 24 кадрам/с поднимает pv до максимума
  секунды; та же ловушка, что описана уроком насыщения E5 в LESSONS, на новом уровне).
- **Пост-хок уточнение метрики (явно помечено, после обнаружения насыщения):** те же данные
  при посекундной конвенции median / first-frame:

|---|---|---|---|---|---|
| max (предрег.) | 100,0 % | 100,0 % | 100,0 % | 100,0 % | 100,0 % |
| median | 100,0 % | 100,0 % | 100,0 % | 98,8 % | 91,0 % |
| first | 100,0 % | 97,6 % | 94,6 % | 92,8 % | 85,0 % |

- **Вердикт по предрегистрированным C2–C4: НЕ ВЫНОСИТСЯ** — он переворачивается от
  соглашения об агрегации (C2 зелёный при median, красный при first), т.е. метрика
  неустойчива на этом материале. FP-ось невычислима в принципе (n=3 ground-бина).
- **ИТОГ it-72 (отрицательный методологический результат):** независимая мультимодальная
  сессия MMAUD **непригодна как подтверждение E6/E8-контура**: одно событийное окно,
  почти нет статики, насыщение max-агрегации. Песочный клип остаётся единственным
  контурным материалом (ограничение it-71 «n=1» НЕ снято) — для главы репро-протокола
  и для планирования: настоящая независимая контурная валидация требует записи второй
  сессии с взлётом/посадкой и фоном (запрос на_data_collection_, вне рамок цикла).
- Справочно (как и предрегистрировано): late D0 на этой сессии — rec 1,8 % (old) / 1,2 %
  (new): непереносимость AST (it-57) убивает fusion-контур при отсутствии информативного
  аудио; независимого суждения о E7/E8 этот материал дать не мог ни при какой политике.
