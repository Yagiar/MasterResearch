# ИТЕРАЦИЯ 51 — Негативная синхронная сессия: FP полноценной системы для цели «airborne» и измеренная неоднозначность целевой переменной

- **Дата:** 2026-09-05
- **Источник:** план it-50 (оценка FP полноценной системы, а не только AST); ревью §3 (присутствие ≠ видимость ≠ полёт).
- **Артефакты:** `research/negative_session_run.sh`, `research/gt_negative_session.csv`, медиа `MasterDiploma/sandboxDataForSimulator/negative-session.mp4/.wav` (17.04 с, нарезка ffmpeg из наземных сегментов 0–10.5 и 66–72.6; вне git), срезы jsonl (offset'ы в `/tmp/negative_session.log`).

## Метод

Негативная сессия — наземные сегменты sandbox-клипа (дрон стоит в кадре, моторы выключены), GT: **airborne=0 всюду, visible=1** (сессия негативна ТОЛЬКО для цели «airborne»; для цели «присутствие» она позитивна — дрон в кадре). Два этапа × 100 с (~5 проходов клипа), Δ=0, τ=0.5, протокол it-45..47 (media_ts-скоринг, сброс групп после остановки, совместные окна).

| Этап | Конфиг | n | FP (decision=true при airborne=0) | Совместных | e2e медиана |
|---|---|---|---|---|---|
| A | per-message, k=0 | 494 | 42 (**8.5%**) | 76.6% | 1.36 с |
| B | watermark, k=5 | 478 | 116 (**24.3%**) | **100%** | 3.18 с |

## Декомпозиция FP (главное)

- **Этап A**: все 42 FP — совместные окна с **p_a медиана 0.57**: аудио реально «звучит дроноподобно» на части сессии (выбег винтов после посадки на 66+ с — физически осмысленный сигнал, который GT «airborne» помечает негативом, it-05). Mono-video FP: 0.
- **Этап B**: все 116 FP — совместные, **p_a медиана всего 0.22** при p_v=0.86. Механизм: каузальная медиана-5 убирает провалы сырого p_a → сглаженное значение держится ~0.22 → p_fused = 0.5·0.86 + 0.5·0.22 = 0.54 ≥ 0.5 → «дрон». **Медиана, повышая устойчивость детекции (it-43: R=0.966), на негативах симметрично повышает устойчивость ложного состояния.**
- mono-video FP отсутствуют в обоих этапах: вклад видео на негативах нейтрален (YOLO теряет стоящего дрона в части кадров — TN).

## Интерпретация (важнее самих чисел)

1. Система уверенно детектирует **присутствие** (видео) и не отличает **«стоит» от «летит»**: для цели «airborne» слияние опирается на p_a, который на наземных сегментах зашумлён выбегом винтов и фоном. Это прямое численное подтверждение тезиса ревью §3 — без раздельной разметки состояний и признаков движения/состояния «airborne»-дискриминация от fused-решения не достигается.
2. «Чувствительная» конфигурация (медиана+watermark) улучшает recall (it-43) и совместность (100%), но **троит FP на негативах** (8.5% → 24.3%) — рабочий выбор конфигурации обязан оцениваться парой «recall ↔ FP на негативах», одной метрикой недостаточно.
3. Честная «пустая сцена» (дрона нет в кадре) в sandbox-материале отсутствует (дрон виден все 73 с) — FP для цели «присутствие» на действительно пустых сценах остаётся неизмеренным (ESC-50 покрывает только аудио, it-50).

## Ограничения

- Сессия 17 с, ~5 проходов; клип нарезан из того же материала, по которому калибровалась система (частично независим: сегменты исключались из «позитивной» оценки it-02..06, но не из обучения моделей).
- FP для цели «airborne» — при трактовке «система сообщает о полёте»; если целевая переменная будет переопределена как «присутствие» (ревью §3), те же решения — TP.
