- **Дата:** 2026-09-21. **Статус:** 🟢 ЗАВЕРШЕНА 21.09: блокатор зелёный (4/4 канонов
  воспроизведены), **H1 КРАСНЫЙ** — merge боксов роняет mAP50; mAP-ось ансамбля закрыта отрицательно.
- **Триггер:** матрица it-76: единственный закрываемый офлайн/инференс-пробел профиля
  «ансамбль» — E2/E3 (mAP на DUT/HF600): голосование по conf (it-74) не определено на уровне
  локализованных событий. Правило из it-74 «merge боксов вне итерации» здесь исполняется
  отдельной итерацией с собственной предрегистрацией.

## Правила ансамбля (pre-defined, ровно два)

- `merge-NMS(IoU=0,5)` := конкатенация детекций обеих моделей, глобальная сортировка по conf
  (детерминированный tie-break: conf → модель(old раньше) → индекс бокса), жадный класс-agnostic
  NMS (один класс drone).
- `WRF` (worst-rank-first, справка, без вердикта) := при совпадении боксов (IoU≥0,5) понижать
  conf худшего из пары до min — реализация: merge-NMS, но второй дубль получает conf=min(conf);
  фиксируется как вторичный репер «согласованность = уверенность».

## Протокол инференса (bit-compat с eval-visual it-65)

imgsz 640, conf 0,001, max_det 300, device cuda (MasterDiploma/venv, ultralytics той же
установки, что канон); материал: `_prepared/visual-{dut,hf}-test600`, split test (600 кадров);
GT — `labels/test/*.txt` + кэш. Метрика — та же функция AP, что в ultralytics val
(`ultralytics.utils.metrics.ap`, all-point), mAP50 и среднее по IoU 0,5:0,05:0,95.

## Предрегистрированные критерии

- **H1 (не-регрессия):** mAP50(merge) ≥ max(mAP50_old, mAP50_new) на ОБОИХ подвыборках
  (каноны 0,7201/0,9059 DUT; 0,8673/0,8830 HF — из `runs/eval/*/metrics.json`).
- **H2 (прирост):** ≥ +0,010 mAP50 хотя бы на одной подвыборке против лучшего одиночного.
- **H3 (не навреди 50-95):** mAP50-95(merge) ≥ mAP50-95 лучшего одиночного − 0,005 на обеих.
- **Валидация конвенции (блокатор интерпретации, до вердикта):** одиночные прогоны тем же
  харнесом воспроизводят канон: |mAP50 − канон| ≤ 0,010 на всех 4 ячейках (old/new × dut/hf);
  mAP50-95 отклоняется >0,020 — харнес считается расходящимся, вердикт H1–H3 не выносится.
- **Правило вердикта:** H1∧H2 (валидная конвенция) → ансамбль-merge = полноценный кандидат
  офлайн-линейки по ВСЕМ визуальным осям (image-pair it-74 + контур it-75 + mAP здесь);
  экспорт всё равно требует решения автора о ×2-доставке и живого A/B. Красный H1 → ансамбль
  остаётся точечной history-находкой (image-линейка), mAP-ось закрыта отрицательно.

## Ограничения (заранее)

1. Одна семка new (унаследовано); тот же test-материал, что E2/E3 для одиночек — сравнение
   поперёк рядов корректно, независимости нет.
2. NMS-merge — не единственный ансамбль боксов (soft-NMS, взвешенный бокс-average вне рамки).
3. HF-домен содержит цели, отсутствующие в train-распределении обеих моделей — ожидаемо low-signal.

## Результаты (21.09 ~22:03 МСК, `research/it77_ensemble_map.txt`)

- **Блокатор валидации конвенции — зелёный:** одиночные прогоны харнесом воспроизвели все
  4 каноны по mAP50 в допуске ±0,010 (Δ: old-dut −0,0039; new-dut −0,0045; old-hf −0,0002;
  new-hf +0,0031; mAP50-95 максимальное отклонение +0,0055) — сравнение корректно.

| subset | old | new | **merge-NMS** | WRF (справка) |
|---|---|---|---|---|
| dut mAP50 | 0,7162 | 0,9014 | **0,8737** | 0,5808 |
| dut mAP50-95 | 0,3811 | 0,5988 | **0,5789** | 0,3982 |
| hf mAP50 | 0,8671 | 0,8861 | **0,8798** | 0,5451 |
| hf mAP50-95 | 0,4159 | 0,4403 | **0,4240** | 0,2875 |

- **H1 КРАСНЫЙ на обеих подвыборках:** merge ниже лучшей одиночки (dut −2,8 п.п.;
  hf −0,6 п.п.); H2 не набран; H3 тоже красный (dut −0,020; hf −0,016 против −0,005-допуска).
- **Механизм отрицания (по данным прогона):** merge-NMS — это ИЛИ по детекциям на уровне
  событий: old-ряд на dut даёт 29 028 детекций против 12 954 у new; при жадном подавлении
  old-мусор с более высоким conf перехватывает матчинг GT и давит true-позитивы new ниже по рангу —
  классическая деградация union-ансамбля без согласования. Конф-голосование it-74 работает
  именно потому, что AND **согласует** модели, а merge боксов — union, и union унаследовал
  FP-профиль old (E1 27,5 %). WRF-справка подтверждает направление: понижение несогласованных
  дублей обваливает mAP (0,58/0,55) — ранг-штраф без удаления лишь множет FP.
- **ВЕРДИКТ по предрегистрационному правилу:** H1 красный → ансамбль остаётся точечной
  находкой image-линейки (conf-AND@0,40 + контурный OR); **mAP-ось (E2/E3) для ансамбля
  закрыта отрицательно**. Пробел E2/E3 матрицы it-76 закрывается этим негативным результатом:
  профиль «ансамбль = AND-ряд conf + OR-ряд контура, НЕ merge боксов» окончательно.
- Инженерные заметки повтора (не влияют на числа): полный список путей в `model.predict`
  при дефолтном кэше датасета убивает процесс OOM-kill'ом (5,7 GB RSS на 7,5-GiB машине) —
  нужны чанки ~150 + `cache=False`; дефолтный batch на GPU даёт CUDA OOM на 6 GiB — `batch=1`;
  `r.path` в ultralytics 8.4.48 при predict — синтетический `imageN.jpg` (ключать по порядку
  отдачи, stream сохраняет порядок); `del model.predictor` ломает `__getattr__`-делегацию —
  только присваивание `None`.
