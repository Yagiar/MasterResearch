## Текущий семестр — НИР-2

Идёт НИР 2-го семестра, тема выше. Рабочий план-график — 7 этапов: 1) инструктаж; 2) определение моделей и методов исследования; 3) выбор и обоснование технологий и оборудования; 4) описание проекта продукта (графические + математические модели); 5) план испытаний + перечень ожидаемых результатов + пробные замеры; 6) пилотные исследования (baseline-ветки + пробный fusion), корректировка плана, обработка/интерпретация результатов; 7) отчёт по НИР (ГОСТ 7.32-2017) + отзыв руководителя + черновик статьи в журнал РИНЦ. Готовый «production» продукт на этом семестре не требуется — нужны проект, обоснование, модели, план испытаний и **пилотные** результаты.

**Архитектура системы (НИР-2):** потоковый пайплайн на брокере **Apache Kafka** с **имитатором источников данных** (сменный источник: replay из публичных датасетов / синтетика → реальные сенсоры в будущем). Источник → топики `video.raw`/`audio.raw` → детекторы-консьюмеры (YOLOv8 + ByteTrack; lightweight CNN по спектрограммам) → топик `inference` → fusion-движок (late→hybrid + adaptive gating + временное выравнивание) → топик `decisions` → sink/дашборд. Опц. «канал деградации» (Δt, frame-drop, шум, отказ канала) для стресс-сценариев. Подробно — в вольте: `00 — Карта/03 — НИР-2 (текущий семестр)/Архитектура — Kafka-пайплайн и имитатор источников.md`.
